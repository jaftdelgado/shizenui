<PropsTable
  showHeader
  props={[
    { name: "variant", type: '"default" | "outline" | "ghost"', default: '"default"' },

    { name: "id", type: "string", default: "generated" },
    { name: "disabled", type: "boolean", default: "undefined" },
    { name: "value", type: "string", default: "undefined" },
    { name: "iconOnly", type: "boolean", default: "false" },
    { name: "pressed", type: "boolean", default: "false" },
    { name: "onclick", type: "MouseEventHandler<HTMLButtonElement>", default: "undefined" },
    { name: "onPressedChange", type: "(pressed: boolean) => void", default: "undefined" },
    { name: "startContent", type: "Snippet<[]>", default: "undefined" },
    { name: "endContent", type: "Snippet<[]>", default: "undefined" },
    { name: "children", type: "Snippet", default: "undefined" },
    { name: "ref", type: "HTMLButtonElement | null", default: "null" }
  ]}
/>

`value` only matters inside a `ToggleGroup`, where it's required to identify the toggle for selection. Standalone, it's ignored — `pressed` controls the toggle directly.
