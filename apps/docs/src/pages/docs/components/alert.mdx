### Compound Components

| Component           | Purpose                                              |
| ------------------- | ---------------------------------------------------- |
| `Alert.Indicator`   | Renders a severity icon or custom children.          |
| `Alert.Content`     | Groups the title and description.                    |
| `Alert.Title`       | Registers an accessible heading with the root alert. |
| `Alert.Description` | Registers supporting text with the root alert.       |
| `Alert.Actions`     | Holds arbitrary sibling actions.                     |
