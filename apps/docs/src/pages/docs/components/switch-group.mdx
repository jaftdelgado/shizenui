## API Reference

### SwitchGroup Props

Groups multiple switches, propagating `disabled`, `readonly`, `invalid`, and `size` to all children
through context. Individual switches can override `disabled`, `readonly`, `invalid`, and `required`
locally. Each child must provide a `value`.
