### Native Forms

Set `name` on a standalone Switch to include its enabled state in native form submission. A
`SwitchGroup` uses a string array value; each child must provide a `value` so enabled switches are
submitted under the group's `name`.

When `required` is set on a standalone Switch, its native mirror must be enabled. When it is set on
a SwitchGroup, the form requires at least one enabled switch. The group uses a nameless sentinel for
that relational constraint, so it does not add an extra FormData entry.
