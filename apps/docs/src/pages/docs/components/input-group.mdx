## API Reference

### InputGroup Props

Accepts all standard HTML `<div>` attributes except `children` and `role`, in addition to the following:

<PropsTable
  showHeader
  props={[
    { name: "variant", type: '"default" | "secondary" | "outline"', default: '"default"' },
    { name: "size", type: '"sm" | "md" | "lg"', default: '"md"' },
    { name: "disabled", type: "boolean", default: "undefined" },
    { name: "readonly", type: "boolean", default: "undefined" },
    { name: "required", type: "boolean", default: "undefined" },
    { name: "invalid", type: "boolean", default: "undefined" },
    { name: "id", type: "string", default: "auto-generated" },
    { name: "ref", type: "HTMLDivElement | null", default: "null" },
    { name: "children", type: "Snippet", default: "—" }
  ]}
/>

### Prefix and Suffix Props

`InputGroup.Prefix` and `InputGroup.Suffix` accept all standard HTML `<div>` attributes, in addition to the following:

<PropsTable
  showHeader
  props={[
    { name: "ref", type: "HTMLDivElement | null", default: "null" },
    { name: "children", type: "Snippet", default: "—" }
  ]}
/>

### Input Props

`InputGroup.Input` accepts all standard HTML `<input>` attributes except `disabled`, `readonly`, `required`, `id`, and `children`. The group owns `disabled`, `readonly`, `required`, and `invalid`.

<PropsTable
  showHeader
  props={[

    { name: "type", type: "HTMLInputAttributes['type']", default: '"text"' },
    { name: "ref", type: "HTMLInputElement | null", default: "null" }
  ]}
/>

### TextArea Props

`InputGroup.TextArea` accepts all standard HTML `<textarea>` attributes except `disabled`, `readonly`, `required`, `id`, and `children`. The group owns `disabled`, `readonly`, `required`, and `invalid`.
