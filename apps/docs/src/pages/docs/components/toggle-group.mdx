## API Reference

### ToggleGroup Props

Groups multiple toggles and propagates `variant`, `size`, and `disabled` to all children. Individual toggles can override `disabled` locally.

<PropsTable
  showHeader
  props={[
    { name: "selectionMode", type: '"single" | "multiple"', default: '"single"' },
    {
      name: "variant",
      type: '"default" | "outline" | "ghost"',
      default: '"default"'
    },
    { name: "size", type: '"sm" | "md" | "lg"', default: '"md"' },
    { name: "orientation", type: '"horizontal" | "vertical"', default: '"horizontal"' },
    { name: "hideSeparators", type: "boolean", default: "false" },
    { name: "disabled", type: "boolean", default: "undefined" },
    { name: "children", type: "Snippet", default: "—" }
  ]}
/>

### Selection Props

`value` and `onValueChange` change shape depending on `selectionMode`: a single string in `"single"` mode, an array of strings in `"multiple"` mode.
